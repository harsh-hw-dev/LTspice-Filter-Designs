# 🔧 Analog Filter Design using LTspice

This repository contains the design and simulation of fundamental analog filters using LTspice. The project demonstrates practical implementation and analysis of Low Pass, High Pass, and Band Pass filters.

---

## 📌 Filters Implemented

### 1. Low Pass Filter (LPF)
- Allows low-frequency signals to pass
- Attenuates high-frequency signals
- Key parameter: Cutoff Frequency (fc)

### 2. High Pass Filter (HPF)
- Allows high-frequency signals to pass
- Blocks low-frequency signals

### 3. Band Pass Filter (BPF)
- Allows a specific range of frequencies
- Rejects frequencies outside the band
